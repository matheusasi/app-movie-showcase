## Regras de commit

- NUNCA adicione o Claude como co-autor dos commits.
- NÃO inclua as linhas `Co-Authored-By: Claude <...>` nem `🤖 Generated with Claude Code` nas mensagens de commit.
- Os commits devem aparecer no GitHub apenas com o autor humano (bonatoneto), sem "and claude" no histórico.
- Ao gerar mensagens de commit, use apenas texto descritivo da mudança, sem assinaturas, créditos ou menções à IA.
- Se for necessário usar `git commit`, monte a mensagem sem os trailers de co-autoria mencionados acima.
